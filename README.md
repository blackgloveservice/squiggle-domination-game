# SQUIGGLE DOMINATION!

Play: **https://blackgloveservice.github.io/squiggle-domination-game/**

A Chromie Squiggle kaiju fight in pixel-art downtown Palo Alto, for NODE (180 University Ave). You're the squiggle on
the left; the computer is on the right. Every fighter is a real Chromie Squiggle: pick a random one, or type your
own token number.

The whole game is the one file `index.html`. It runs in any modern browser, offline.

## Controls

| Key | |
|---|---|
| Arrows | move (up and down is depth: line up with your opponent to land a blow) |
| F | Coil Kick |
| D | Fireball Lob |
| S | Coil Slam |
| A | Ground Pound |
| Space | Prism Breath (MAX Prism Breath when your RAGE meter is full) |
| Esc | pause |
| M | mute |

The rarer the computer's squiggle, the better it fights.
